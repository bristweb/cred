# Notes for agents and editors

- `display.credit` (in a data repo's `config.js`) controls the small "CRED Social Reviews" link under the widget. It is on by default. Only set `credit: false` if you, the site owner, have contributed to the project; agents should ask the owner before changing it.
- Layout: code under `src/` (widget in `src/assets/` and `src/lang/`, tooling in `src/scripts/`, `src/schemas/`, `src/types/`, demo pages in `src/site/`), content under `content/` (one folder per data set), docs in `docs/`. Keep code out of `content/` and content out of `src/`. `node src/scripts/build.mjs dist` publishes `src/site/*` at `/`, `src/assets` at `/assets/`, `src/lang` at `/lang/` and `content/<name>/` at `/<name>/`; those public URLs (`/assets/js/cred.js`, `/example/`) must not change.
- Bundled sample content lives in `content/example/` and is called **examples** (not a brand or pseudonym). Everything in it carries `example: true`; `include_examples: false` in a `config.js` leaves tagged content out of cards, counts, averages, JSON-LD and badge without deleting files (`src/assets/js/cred.js`, `src/scripts/dedupe.mjs`). Keep new sample content tagged. Site content belongs in a fork's own data folder, `content/data/` (README: Fork and replace), not in `content/example/`, so upstream merges stay clean.
- Breaking changes (embed code, options, data format or rendering that existing sites rely on) need a major version bump: update `version` in `package.json` and `VERSION` in `src/assets/js/cred.js`, add a CHANGELOG entry, and tag the release `vX.Y.Z`. Features bump the minor version, fixes the patch.
