# Your data (starts as the Cred demo)

Everything the widget shows comes from this folder. It starts with fictional examples for a bike shop, the same content shown at [cred.bristleconeweb.com](https://cred.bristleconeweb.com/). **Replace it with your own before publishing.**

Edit these files in GitHub (pencil icon, or **Add file → Upload files**); every push is checked by the Check action. Updates from Cred change only `package/`, never this folder. See [Cred's data format guide](https://github.com/bristweb/cred/blob/main/docs/REFERENCE.md#data-format) for field details.

## Layout

- `config.js` — business, platforms, display, summary, optional accolades, credentials and testimonials, and `reviews.years`; also `include_examples` and optional language settings
- `lang/` — optional UI wording listed in `languages` (partial files are fine; English is built in)
- `reviews/<year>.json` — review records
- `theme/theme.css` — `--rw-*` colors for light and dark mode
- `assets/` — local files grouped by kind: `icons/` for logos and badges, `images/` for photos and posters (`images/reviewers/` for avatars), `video/`, `audio/`, and `ATTRIBUTION.md`
- `badge.json`, `badge.svg` — generated by `node package/tools/badge.mjs`
- `cred-config.d.ts` — editor type hints, generated by `npm run types`
