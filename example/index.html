CRED example: Northwind Cycles

Fictional example data for a bike shop, shown with the CRED reviews widget.

How to embed

  1. Copy the snippet. 
    <script src="https://cred.bristleconeweb.com/assets/js/cred.js" data-source="https://cred.bristleconeweb.com/example/" defer></script>
  2. Paste it into your site's HTML where the reviews should appear:
    • Framer: Insert → Embed, choose HTML, paste.
    • Google Sites: Insert → Embed → Embed code, paste. Add data-constrained="true" and size the box.
    • Squarespace: Code block. Wix: Embed code → Custom code / HTML iframe.
    • WordPress: Custom HTML block.
    • Any other site: paste into the page HTML.
  3. That's it. The widget adapts to the width it's given. Optional data-* attributes (layout, theme, limit, data-constrained for fixed-height boxes) are listed in the options.
  4. Make your own. Copy the example data folder into a new repo, add your reviews, publish it, and point data-source at its address. Setup guide: github.com/bristweb/cred.

Please don't embed or link to this page itself; paste the snippet on your own site.
